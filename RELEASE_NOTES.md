## ORBIT // STORE v1.1.0

Everything in one place.

- New catalogs in Browse: KernelSU Next Modules Repo and Magisk Modules Alt Repo, with source labels and tags
- Alt Repo modules are rebuilt on the device from their source archive into a flashable ZIP
- KSU Next modules install from the latest GitHub release, verified with the GitHub asset digest when available
- New Lists tab: Awesome Android Root (16 categories), Awesome KernelSU and the essential root modules gist, grouped by category with search
- GitHub entries in the lists open a Releases sheet with Install
- Settings: turn each extra catalog on or off
- Update detection for installed Alt Repo modules
- Module IDs that start with a digit are accepted
- Installs without a checksum always ask first
